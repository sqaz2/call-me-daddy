AAndroidPhones, tablets & foldables

Install with Chrome or Samsung Internet

  1. Open this page in Chrome.
  2. Tap ⋮ → Install and create shortcut → Install. Some versions call it Add to Home screen or Install app.
  3. Open MusicSubject from your home screen or app list.

Samsung Internet: tap the install icon in the address bar when it appears, then choose Install on your Apps screen.

Device families: Google Pixel; Samsung Galaxy S, A, Z Fold, Z Flip and Tab; Motorola Moto and Razr; OnePlus; Xiaomi, Redmi and POCO; OPPO; vivo; Nothing; Sony Xperia; Nokia/HMD; Fairphone; and Android tablets from Lenovo and other brands.

iiPhone & iPadAdd to your Home Screen

Install with Safari

  1. Open this page in Safari.
  2. Tap Share → Add to Home Screen. On iPad, you may need View More.
  3. Keep Open as Web App turned on if shown, then tap Add.

Device families: iPhone, including SE, Plus, Pro and Pro Max; iPad, iPad mini, iPad Air and iPad Pro with an up-to-date supported browser.

WWindowsLaptops, desktops & Surface

Install with Edge or Chrome

  1. Open this page in Microsoft Edge or Chrome.
  2. Click the app install icon in the address bar, then Install.
  3. In Chrome, you can also use ⋮ → Cast, save and share → Install page as app.

Device families: Windows PCs from Dell, HP, Lenovo, ASUS, Acer, MSI and other makers; Microsoft Surface; custom desktops. Use a browser that still supports your Windows version.

MMacMacBook, iMac, mini & Studio

Add to Dock with Safari, or install with Chrome

  1. On macOS Sonoma 14 or later, open this page in Safari.
  2. Choose File → Add to Dock → Add.
  3. Open MusicSubject from the Dock or Applications.

Chrome option: use the address-bar install icon, or ⋮ → Cast, save and share → Install page as app. This is also an option on older Macs whose macOS version is still supported by Chrome.

Device families: MacBook Air, MacBook Pro, iMac, Mac mini, Mac Studio and Mac Pro, with a supported operating system and browser.

Install with Chrome

  1. Open this page in Chrome.
  2. Click the install icon in the address bar, or use ⋮ → Cast, save and share → Install page as app.

Device families: Chromebooks and Chromebook Plus laptops from Acer, ASUS, HP, Lenovo, Samsung and others; ChromeOS tablets and Chromebox desktops. School or work policies may restrict installation.

LLinuxSupported desktop distributions

Install with Chrome

  1. Open this page in a supported version of Chrome.
  2. Use the install icon in the address bar, or ⋮ → Cast, save and share → Install page as app.
  3. Choose Install. Your desktop environment controls where the launcher appears.

Device families: laptops and desktops running a Linux distribution supported by Chrome. Chromium-based browsers may also offer installation; menus and media support vary by distribution.

Another device or browser?

Facebook, Instagram or another app’s browser: open this page in Chrome, Safari or Edge first. If there’s no “Open in browser” option, copy its address into your browser.

Fire tablets, Huawei/HarmonyOS, older devices or another browser: try listening on the website. Installation and background playback vary; these setups haven’t been verified.

Smart TVs, streaming sticks, game consoles, watches and car dashboards: there’s no dedicated MusicSubject app for these yet. A working device browser may open the website, but playback and remote controls aren’t verified.

Keep the music with you

Press play before switching apps or locking your screen. Keep the app open in the background.

Songs stream over the internet. Offline song downloads aren’t included yet. Battery settings, other audio apps and browser restrictions can still interrupt playback. Installing the web app doesn’t guarantee uninterrupted background audio on every device.
